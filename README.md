### Зачем я это сделал?

Этот проект вырос из простого желания создать интерактивное пространство, на которое приятно смотреть. Здесь нет игровых целей, очков или таймеров. Это интерактивная живая картина. 

Вы можете наблюдать, как звёздный газ закручивается вокруг горизонта событий сверхмассивной чёрной дыры, смотреть сквозь искажения червоточины в альтернативную вселенную или рассматривать сложную геометрию сферы Дайсона. 

Вся визуализация работает прямо в браузере за счёт ресурсов вашей видеокарты. Никаких тяжёлых бандлеров, никакого бэкенда — чистый ванильный JavaScript, библиотека Three.js и математика в GLSL-шейдерах.

### Что под капотом?

* **Шейдерный реймарчинг** — все ключевые космические аномалии визуализируются на GPU через алгоритм raymarching (60–80 шагов на луч).
* **Объёмные туманности** — реалистичные газы и пылевые облака (М42 в Орионе, Крабовидная туманность и Конская Голова) со сложными градиентами без использования плоских спрайтов.
* **Чёрная дыра (Sagittarius A\*)** — симуляция искривления лучей света (гравитационное линзирование) по метрике Шварцшильда с учётом релятивистского эффекта Доплера (смещение цвета и яркости вращающегося газа).
* **Проходимая червоточина** — мост Морриса-Торна. При приближении к горлу координаты пространства инвертируются, перенося вас в альтернативную вселенную с совершенно другим звёздным небом.
* **Сфера Дайсона (Kepler)** — футуристический рой солнечных коллекторов вокруг звезды с пробивающимися сквозь зазоры лучами света и светящимися энергосетями.
* **Карта Млечного Пути** — 55 000 частиц, формирующих спиральные рукава, пылевой диск и яркий балдж.
* **Эстетика терминала** — атмосферная загрузка системы в стиле бортового компьютера (с проверкой подсистем и калибровкой навигации).

### Математические основы симуляции

Для тех, кому интересны детали реализации физики на GPU:

1. **Искривление траектории света:** свет гнётся на каждом шаге трассировки луча в соответствии со Шварцшильдовским приближением:
   $$\vec{a} = -1.5 \cdot R_s \cdot \frac{|\vec{L}|^2}{r^5} \cdot \vec{p}$$
   Где $\vec{L} = \vec{p} \times \vec{v}$ — угловой момент, а $R_s$ — радиус горизонта.
   
2. **Трёхмерный диск аккреции:** объёмная плотность газа задаётся как функция от расстояния и высоты над плоскостью диска с наложением фрактального шума (FBM):
   $$\rho(r, y) = \text{WarpedNoise}(r, \theta) \cdot \exp\left(-\frac{y^2}{h^2}\right)$$

3. **Релятивистский биминг:** яркость и цвет диска зависят от направления вращения плазмы относительно наблюдателя:
   $$D = \frac{1}{\gamma \cdot (1 - \beta \cos\theta)}$$

4. **Координатная инверсия червоточины:** при прохождении критического радиуса горла червоточины ($r < R_s$) координаты точки меняются на противоположные в альтернативном пространстве:
   $$\vec{p}_{new} = -\vec{p} \cdot 1.01$$

### Быстрый старт

Проект полностью автономен. Единственное ограничение — современные браузеры блокируют загрузку шейдеров по протоколу `file://` из соображений безопасности (CORS). Поэтому для запуска нужен простейший локальный сервер.

```bash
# Клонируем репозиторий
git clone https://github.com/vincere-mori/stellar-cartography.git
cd stellar-cartography

# Запускаем локальный веб-сервер (встроенный в Python)
python -m http.server 7821
```

После этого откройте в браузере: **`http://localhost:7821`**

#### Десктопная версия (OpenGL / Python)
Если вы хотите запустить проект локально в качестве отдельного приложения:
```bash
pip install -r requirements.txt
python main.py
```

### Используемые технологии

* **Интерфейс и логика:** Ванильный ES2022 JavaScript + CSS3
* **Десктоп-версия:** Python 3 + PyOpenGL + GLFW
* **Сборка:** Не требуется (zero-bundler, всё работает из коробки)
